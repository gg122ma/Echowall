# EchoWall

**EchoWall** is a smart campus community and information platform designed for students of **Kolej Matrikulasi Kedah (KMK)**.

It brings campus information, building guidance, student community features, study resources, and AI-assisted campus support into one responsive web experience.

## Live Website

**https://gg122ma.github.io/Echowall/**

## Main Features

### Ask Echo

Ask Echo is EchoWall's campus guide.

It helps students find verified KMK information such as:

- building locations
- opening hours
- campus services
- facility information
- rules and access information
- supported campus navigation

Answers are grounded in the available KMK campus sources. When information cannot be verified, EchoWall avoids guessing.

### KMK Map

The interactive KMK Map helps students explore campus buildings and facilities.

Supported building records can connect directly to their corresponding location on the map.

### Building Stories

Students can explore information about KMK buildings and facilities through dedicated building views.

Building information is shared across the campus guide, map, and building-detail experience to keep the platform consistent.

### KM Community

EchoWall provides building-based community spaces where students can share information, experiences, notices, and discussions related to campus life.

### Study Resources

The Study section provides access to student learning resources and notes in a structured campus environment.

### Multilingual Interface

EchoWall supports:

- English
- Bahasa Melayu
- Chinese

The interface is designed for the multilingual environment of Malaysian students.

### Account and Session Support

EchoWall uses persistent authentication so users can remain signed in while navigating between major parts of the platform.

Administrative areas are separated from normal student access.

## Technology

EchoWall is built with a lightweight web architecture using:

- HTML
- CSS
- Vanilla JavaScript
- Hash-based routing
- Leaflet
- Supabase
- GitHub Pages

The project avoids unnecessary framework dependencies and keeps major campus features modular.

## Campus Information Philosophy

EchoWall prioritizes **verified campus information over generated guesses**.

Campus facts, building identities, map targets, service information, and opening hours are handled conservatively.

When a location or fact cannot be confirmed from available sources, EchoWall may return an unsupported or uncertain result instead of presenting unverified information as fact.

## Mobile Support

EchoWall is designed with mobile use as a primary experience.

Major features including Ask Echo, KMK Map, Community, Building Stories, and Study Resources are designed to work across mobile and desktop layouts.

## Project

EchoWall is developed as part of the **InnoSTEM 2026** project.

Its goal is to make campus information easier to discover while creating a shared digital space for KMK students.
